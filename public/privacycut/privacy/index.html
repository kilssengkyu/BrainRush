1. 사진과 인식 정보

사진 선택, 문자 인식(OCR), 개인정보 후보 탐지, 얼굴·QR·바코드 위치 탐지, 가림과 결과 파일 생성은 기기 안에서 이루어집니다. 사진 원본, 인식한 글자, 얼굴·QR 정보는 운영자 서버나 외부 AI 서비스로 전송하지 않습니다. 얼굴은 가릴 위치를 찾는 데 사용하며 사람을 식별하거나 얼굴 인식 데이터베이스를 만들지 않습니다.

회원가입과 자체 백엔드·데이터베이스는 없습니다. 운영자가 사진이나 인식 결과를 수집해 광고·분석·AI 학습에 사용하는 기능도 없습니다.

2. 기기 내 저장과 삭제

  • 작업 사진·중간 파일: 사진 처리에 필요한 동안 앱 전용 작업 저장소를 사용합니다. 작업이 끝나면 정리하고, 중단 후 남은 파일은 다음 앱 실행 시 정리합니다. 작업 파일은 OS 백업에서 제외합니다.
  • 공유용 결과: 수신 앱이 읽을 수 있도록 임시 보관합니다. 24시간이 지난 파일을 다음 앱 실행 시 정리하므로 앱이 실행되지 않으면 더 오래 남을 수 있습니다.
  • 지정 문구: 사용자가 직접 등록한 이름·가게 이름 등의 문구는 반복 가림에 사용하며, 백업에서 제외되는 앱 전용 저장소에 보관합니다. 상세 설정에서 삭제할 수 있고 PRO 권한이 없어져도 삭제할 수 있습니다. OCR 결과를 이 목록에 자동 저장하지 않습니다.
  • 설정·구매 권한·광고 보상: 테마와 검사 설정, 확인된 PRO 권한, 미사용 광고 보상을 기기에 보관합니다. 보상 중복을 막기 위한 무작위 식별자에는 사진·인식 내용·사진 해시·사진 경로·가림 좌표를 넣지 않습니다.

앱 삭제 또는 앱 데이터 초기화로 앱 전용 데이터가 제거됩니다. 이미 사진 보관함이나 다른 앱에 저장·공유한 결과는 해당 서비스에서 별도로 삭제해야 합니다. 지정 문구와 미사용 광고 혜택은 앱 삭제 후 복원되지 않습니다.

3. 사진 접근과 공유

사진 선택과 저장에 필요한 범위에서 OS 사진 선택기와 권한을 사용합니다. 클라우드에만 저장된 사진을 선택하면 Apple·Google 등의 사진 서비스가 원본을 내려받기 위해 인터넷에 연결할 수 있습니다.

가림 결과는 원본을 덮어쓰지 않고 새 파일로 생성합니다. ‘사진 정보 삭제’ 옵션을 켜면 원본에 포함된 GPS 위치, 촬영 시각, 촬영 기기 등의 민감한 메타데이터를 제거합니다. 옵션을 끄면 지원되는 일부 정보를 유지합니다. 사진 속에 눈에 보이는 정보의 가림은 별도로 선택해야 합니다.

저장된 결과가 iCloud·Google Photos 등에 동기화되는지는 사용자의 OS·사진 앱 설정에 따릅니다. 공유 기능은 사용자가 선택한 앱이나 수신자에게 결과 파일을 전달하며, 이후의 처리는 해당 서비스의 정책에 따릅니다.

4. 광고와 개인정보 선택

무료 버전은 Google AdMob 배너 및 사용자가 선택하는 보상 광고를 제공합니다. 광고 제공·보안·부정 사용 방지·성능 측정 과정에서 IP 주소와 이에 기반한 대략적 위치, 기기·앱 식별 정보, 광고 상호작용, 진단·성능 정보 등이 Google에 전달될 수 있습니다. 앱은 사진·OCR 결과·가림 영역을 광고 SDK에 제공하지 않습니다.

맞춤 광고를 요청하지 않고, iOS의 광고 추적 권한을 요청하지 않습니다. Android 광고 ID 관련 권한과 게시자 퍼스트 파티 ID 사용도 비활성화합니다. 비맞춤 광고도 광고 제공과 부정 사용 방지 등을 위한 정보 처리가 있을 수 있습니다.

필요한 지역에서는 Google UMP를 통해 동의와 개인정보 선택지를 제공합니다. 선택지 변경이 필요한 경우 앱 홈에 표시되는 ‘광고 개인정보 설정’에서 변경할 수 있습니다. 광고를 이용하지 않아도 기본 사진 처리는 가능합니다. PRO 권한이 확인된 사용자는 광고를 요청하지 않습니다.

광고 정보의 보관, 처리 위치와 이용자 선택에 관한 내용은 Google 개인정보처리방침과 Google 광고 기술 안내를 확인해 주세요. Google은 여러 국가의 서버에서 정보를 처리할 수 있습니다.

5. 구매와 복원

PRO 결제·구매 확인·복원·환불은 Apple App Store 또는 Google Play를 통해 처리됩니다. 앱은 스토어가 제공하는 상품·거래 식별 정보와 구매 상태를 이용해 권한을 확인하고, 확인된 권한을 기기에 보관합니다. 운영자는 결제 카드번호를 받거나 자체 서버에서 영수증을 보관하지 않습니다.

구매·복원과 온라인 구매 상태 갱신에는 스토어 통신이 필요합니다. 확인된 구매 권한으로 기기에 저장된 사진을 오프라인에서도 처리할 수 있습니다. 스토어의 정보 처리에는 Apple 개인정보처리방침과 Google 개인정보처리방침이 적용됩니다.

6. 문의와 웹사이트

이메일로 문의하면 이메일 주소, 문의 내용과 사용자가 자발적으로 첨부한 자료를 문의 응대와 문제 해결에 사용합니다. 필요한 범위를 넘는 개인정보나 원본 사진을 보내지 말아 주세요. 문의 목적을 달성한 정보는 지체 없이 삭제하며, 법령에 따른 보관 의무가 있는 경우에는 해당 기간 동안 보관합니다.

문의 이메일은 Google Gmail을 통해 처리됩니다. 이 안내 웹사이트는 Vercel에서 제공되며, 페이지 제공·보안·운영을 위해 IP 주소, 요청 시각, 브라우저·접속 기록 등이 호스팅 서비스에서 처리될 수 있습니다. 자세한 내용은 Vercel 개인정보처리방침에서 확인할 수 있습니다.

개인정보 컷 안내 페이지에는 자체 광고·방문 분석 스크립트나 사진 업로드 기능을 넣지 않습니다. 같은 사이트의 BrainRush 서비스로 이동하는 경우에는 BrainRush 개인정보처리방침이 적용됩니다.

7. 이용자 권리와 보호 조치

기기 내 지정 문구는 상세 설정에서 삭제하고, 사진 접근 권한은 OS 설정에서 변경할 수 있습니다. 운영자에게 보낸 문의 정보의 열람·정정·삭제·처리 정지를 원하면 아래 이메일로 요청해 주세요. 본인 확인 후 관련 법령에 따라 처리합니다. 운영자가 보유하지 않는 기기 내 원본 사진이나 OCR 결과는 원격으로 조회·복구할 수 없습니다.

앱 전용 저장소와 OS의 접근 제한을 사용하고, 민감한 OCR 원문이나 사진 경로를 앱 로그에 기록하지 않습니다. 사진 처리용 임시 파일과 지정 문구는 백업에서 제외하며 필요가 없어진 작업 파일은 정리합니다.
